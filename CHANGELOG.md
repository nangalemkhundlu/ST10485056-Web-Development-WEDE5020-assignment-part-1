## [1.0.0] - 2026-08-11

### Added

* Created the five main pages for the Sisonke Auto Care website.
* Added a home page introducing Sisonke Auto Care and its services.
* Added an About page with information about the business, mission, vision and values.
* Added a Services page describing the automotive services provided.
* Added an Enquiry page where customers can request information, quotations or services.
* Added a Contact page containing business contact information.
* Added navigation links between all website pages.
* Added consistent headers and footers across the website.
* Added images and automotive-related graphics to support the website content.
* Added HTML forms with required fields and basic HTML validation.
* Added responsive viewport settings to improve the website on different devices.
* Added page titles and descriptions for the website pages.
* Created a README file containing information about the project, folder structure and how to run the website.
* Added the project to GitHub for version control and tracking changes.
