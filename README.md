# Sisonke Auto Care Website

A five-page HTML5 website developed for Sisonke Auto Care. The website provides customers with information about the business, its automotive services, and ways to make enquiries, request quotations, and contact the business.

## Pages

* `index.html` — Home page introducing Sisonke Auto Care and highlighting its services
* `about.html` — Information about the business, including its mission, vision, values and target customers
* `services.html` — Information about the vehicle maintenance and repair services offered
* `enquiry.html` — Form for customers to make enquiries, request quotations or book a service
* `contact.html` — Business contact information and a contact form

## How to Run the Website

1. Download or clone the project from the GitHub repository.
2. Open the `NANGALE MKHUNDLU WEB5020 Assignment 1` project folder.
3. Open `index.html` in a web browser.
4. Use the navigation menu to move between the five pages.

The website is a front-end HTML project and does not require any installation or additional software to run.
